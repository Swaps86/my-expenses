My Expenses - Android project (version 1.0.0)
1. Make a free GitHub account and create a new repository.
2. Upload everything in this folder (keep the .github and native folders).
3. Open the Actions tab, run "Build APK", wait about 5 minutes.
4. Download "my-expenses-apk" from the finished run, unzip, install app-debug.apk on your phone.
5. In the app: Manage > Auto-add from SMS, switch on, allow SMS.
If Android blocks SMS: Settings > Apps > My Expenses > menu > Allow restricted settings, then try again.
